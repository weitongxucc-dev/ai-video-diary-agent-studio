本文件只保留版本范围的覆盖索引、验收样本与尚待决定项，不复制产品规则、动态完成状态或文件所有权。产品范围由[产品需求](../docs/product-requirements.md)拥有；实际实现和交付分别查代码、Git/PR、CI及真实证据。R/W/E编号为已有需求的追踪键，不表示已实现。

当前实施范围和唯一负责人见[活动合同](active-contract.md)。旧工作树、旧派工与已关闭合同均不产生新写权。新请求先检查当前实现，复用既有能力，不按本清单重做一遍。

## 4. 真实验收场景

| 用例 | 最少实际动作 | 通过标准 |
| --- | --- | --- |
| A 素材理解 | 导入产品/人物/屏录素材→分析→自然语言搜索→定位原片→纠正标签→再次检索 | 时间与观察可追溯；纠正保留；无关/缺素材能识别 |
| B 原声口播 | 切停顿→调声音→字幕纠错→导出 | 原声与嘴型同步；修改不误触发生成配音 |
| C 生成人物 | 最终配音→人物片段→改一句→局部重做 | 相应口型失效正确；其他片段不重做；人工看片合格 |
| D 产品介绍 | 目标→资料→文案→选片→替换候选 | 型号/动作对应，出处相关；不拿泛化素材冒充事实 |
| E 多轨混音 | 导入音乐/音效→移动/剪切→压低音乐→淡出→静音/独听→导出 | 波形来自实际音频；监听与导出语义正确；最终音轨齐全 |
| F 画面处理 | 裁切→调色→轻美颜→转场→叠字→撤销 | 真实前后预览、效果稳定、撤销恢复、预览与成片一致 |
| G 双语与字幕 | 翻译→改译文→拆并/调时轴→关闭英文→恢复 | 错误可恢复、不破坏中文轨；无溢出或错误覆盖配音 |
| H 连续改片 | 指代→复合修改→实际回读→撤销/重做 | 定位、约束、版本和依赖正确，所有E01–E18具备对应入口 |
| I 模板新主题 | 保存设置→选版本→换主题→预检→新任务 | 设置生效，缺声音明确；旧文案、任务与成片不变 |
| J 异常与外接盘 | 隔离数据下模拟缺盘/不可写/缺文件/中断/重启/重复提交 | 不回退内置盘、不重复生成、不丢有效状态；不拔正在写入的真实数据盘 |
| K 独立交付 | 从外接盘启动测试包→打开任务→原生导出→文件管理器打开 | 候选身份一致，Git/开发服务不被误当成包环境，文件实际可用 |

时间与媒体检查：确定性编辑以输出帧/音频采样时间基准核查，目标是在约定边界内不超过一个输出视频帧的计算偏差；这不作为口型自然度或字幕声学对齐的自动通过阈值，后两者另做真实试听/看片。所有输出检查无新增黑帧、拉伸、截断、明显削波与不可解释的时轴漂移。

布局尺寸与组件交互按[DESIGN可见验收](../DESIGN.md#7-可见验收)选择受影响场景，本清单不另定尺寸矩阵。

断网验证：模型下载完成后，在隔离验证环境禁止外部访问，执行本地分析/检索/编辑并检查出站尝试；不为测试改变用户全机网络。外部文字能力另行标记，不能因局部离线成功声称全应用离线。

以下交叉场景沿A–K及E01–E18验证，不以原型替代：

1. 一人启用到四人、第五人加入、超额并发邀请失败、撤销/过期/重复绑定；停用不丢内容。
2. 私有素材/声音/资料与共享内容正确召回；主账号不能越权读私有原件，成员不能从词云/缓存/助手泄露他人内容。
3. 混合批次无说明可分析，有说明提高理解；红烧肉纠正影响真实检索和替换，重分析保留人工事实。
4. 完整文件自动分析、复制中跳过、补扫/重启幂等，导入不自动制作；素材可用阶段准确可见。
5. 知识文件/链接有结构参数和来源快照，矛盾参数不混用，文案引用可回查，恶意资料指令不执行。
6. 03镜头换更好素材：定位对象→相关候选→保持配音/锁定约束→直接编辑→真实预览→版本/撤销。
7. 本人电脑录音试听应用；声音克隆、英文/混读、人物口型分别验证，不合格明确缺口。
8. 模板与定时任务生成新候选，文案/发布确认仍需人；错过夜间窗口和关客户端不丢任务。
9. 五个真实会话同机：预览/录音、导出、局部预览、导入、编辑排队；按PRD12.1测响应/连续性/峰值/公平/解析推进，不能以模拟互斥代替。
10. 发布/数据逐平台验证真实结果和权限；外接盘故障、重启、恢复、导出及同候选测试包均留证。

Pi 与脚本还需覆盖：完整对象/schema发现，明确单位与省略/清空语义；Code Mode有界复合调用及失败后原请求查询；授权媒体脚本实际视听、文件/网络隔离和完整进程释放；成功配方在另一输入和新会话复用；后台结果接续、插话/停止/重启及晚回包；外部CLI与GUI同版本回读、撤权/跨空间和未知结果恢复。已具备的节点复用有效证据，新增媒体类型不由单PNG实测外推。
