## 5. 本地多模态技术方案与选型门禁

### 5.1 处理链

1. 文件探测：复用FFmpeg/ffprobe识别音视频流、时长、方向和格式；保存源指纹。
2. 初始片段：镜头变化与静音提供候选切点；结合转写和动作边界修正。先引用源时间区间，不默认复制大量切片文件。
3. 听觉：优先复用现有本地Whisper，识别真实语言，保存转写时间；字幕精确对齐另做验证，不把粗略ASR时戳当逐词真值。
4. 文字：本地OCR候选优先评估macOS原生能力；中文、英文、小字和屏录用例分别验证。OCR不能靠“VLM大概读出来”替代。
5. 视觉：静态片段少量代表帧，动态片段按时间有序抽帧；疑难区间增加采样或局部分析。画面描述必须保留证据帧/时间。
6. 融合：合并可追溯的观察，不把声音提及的产品自动标成画面真实对象。输出未知和疑点，不要求模型填满所有标签。
7. 索引：结构化过滤、文字和视觉索引协作，沿现有资产和存储；模型/参数变化时可增量重建。
8. 反馈：用户纠正事实与本次/长期偏好分开；再次分析不覆盖人工纠正。

### 5.2 4B设备实验

同一批授权本地短样本比较4B量化与2B量化，记录：模型精确版本/校验值、输入帧数与尺寸、加载耗时、逐片段分析耗时、内存峰值、交换压力、持续运行温度/性能表现及错误输出。质量核查覆盖主体、动作顺序、屏幕文字、产品身份与不知道时的表达。量化版本与运行时锁定后才能形成可复现基线。

样本至少包含：静态产品、接口操作、人物口播、屏幕教程、光线差或快速动作、中英文字画面。先验证离线下载后的运行，再在应用中验证资源让行。4B若无稳定质量收益或明显影响剪辑，提供实测取舍；不自动增加云调用。该实验尚未执行，不给出未经测量的速度或内存承诺。

### 5.3 检索与重排实验

对人工标注的“文案需求—合适片段/缺素材”样本记录候选召回、首选保留和错误类型。先对比当前算法与多路召回，再只对候选评估本地重排；另验整片重复与节奏。缺素材样本必须入集。重排方案仅在改善用户选片且耗时可接受时接入，不能强制所有片段反复运行VLM。

### 5.4 对话模型与后台模型分工

0.11 用户对话、文案和编辑意图使用外部文字模型；MiniMax-M3 为首选，DeepSeek 保留主动切换。对话 Agent 优先复用 Pi 的会话和工具调用，不另写通用 Agent 循环；产品业务工具仍走现有 Plan、EditProposal、CreationTask 和版本路径。后台本地 4B 只负责素材解析。对话请求仅发送必要的文字上下文与筛选证据，不发送原始媒体或整库；界面展示服务、数据类型和费用边界，不自动切换供应商。模型下载、依赖安装与外发/付费是不同动作，实际收费调用仍按授权边界执行。

## 9. 自然语言执行与预览协议

模型只产生结构化意图/操作计划，不直接提供可执行shell。每个工具有适用对象、参数边界、成本/耗时信息、可取消性和失效关系。明确范围不重复提问；含糊且影响不同结果时展示候选。

真实预览策略：构图/图文提供画面预览；调色/美颜/转场提供短片段前后对比；音轨提供选区试听；多轨时间变化提供同步视听片段。预览是派生产物，取消后不改变当前有效版本。正式输出使用同一参数和执行语义，预览的低分辨率必须明确标记。

“刚才那段”“再弱一点”绑定当前对话中的具体对象与操作，不只依赖最后一条字符串。切换任务清理错误上下文；旧提案遇到新版本需重新核查，不能自动覆盖。未支持指令应说明缺的能力与可执行替代，不伪造成功。
