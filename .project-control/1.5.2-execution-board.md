## 验收顺序

1. 主控复核 DG-1、AG-1、AS-1 的 canonical 代码和证据，补齐真实素材/输出观察缺口。
2. 沿已有 CLI-1、MOB-1 线程完成接口、授权、工作区和成片下载的真实入口验收。
3. 为 SET-1 绑定一个已有可见执行线程，先做设置内容分层和状态表达，再做视觉与交互检查。
4. 只在前述能力稳定后执行 CLN-1：先保留安全快照和清单，再处理过期 worktree、缓存、临时测试目录和 stale refs；模型、真实素材、成片、数据库和验收证据必须逐类确认后再动。
5. GitHub 清理按“已合并/已废弃/仍有价值/当前未发布”分类；远程删除和默认分支调整必须在具体清单可审查后再执行。
