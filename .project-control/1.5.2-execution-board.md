**贯穿各阶段的责任。** 主控维护作品、语言、选区和版本的共享约定，派工给原有可见 Codex 对话，检查实际差额并合并。写入范围按工作台、素材、Agent/媒体分开；设计线程按 [DESIGN.md](../DESIGN.md) 对照普通、窄窗、明暗和异常状态。Windows 从第一阶段沿[原分支](../docs/windows-branch-migration-2026-11-13.md)同步同一候选，独立验证窗口与缩放、文件路径和锁、模型执行、退出恢复及成片播放。目标机暂缺时，保留对应待验项，其他工作照常推进。

**排程取舍。** 本地画面解析、素材用途、Pi 工具执行、结果回查与撤销优先服务前三阶段。需要时在原用例处修职责或事务问题。通用技能目录扩容、批量排期、发布数据看板和目录清理排在首条交付与复用之后。手机、CLI/MCP、飞书/钉钉及三平台发布仍沿[既有开发清单](0.11-development-plan.md)和[产品发布范围](../docs/product-requirements.md)验收；本表的双语交付里程碑只到本地文件。各阶段的用户测试数字均为目标，实测结果随对应样本、原请求、产物或 PR 留证。

## 项目基本情况

当前是以电脑端为核心的本地 AI 视频工作台：Next.js/React 负责编辑界面，FastAPI 与本地数据库保存业务事实，Pi 通过既有工具调用领域用例，Electron 管理本机服务与渲染，Flutter 手机端和 CLI 复用授权接口。已完成真实视频与部分资源的采用、渲染、观察和人工播放验收；仍处于功能补齐和跨平台验收阶段，不能视为全功能稳定发行版。

本次不重跑未受影响的真实成片，不把分支同步当作 Windows 真机通过；安装包版本及剩余事项见下表。
