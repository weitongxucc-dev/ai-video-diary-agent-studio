# 手机与电脑版连接联调要求

接入目标为电脑上的曜核软件与 Flutter 手机 App 在同一局域网连接；不依赖蓝牙配网或实体机箱屏幕。

本文件提供两端代码入口与联调检查范围，不另定义产品、安全或API协议。产品范围见[产品需求](../../docs/product-requirements.md#11-版本交付边界)，账号和空间约束见[认证边界](../../docs/auth-workspace-boundary.md#9-主账号邀请与共享授权)，正式连接、传输与信任协议由[架构§5.1.1](../../docs/system-architecture.md#511-手机联动的共同接收与回读)拥有，跨端接受点见[联合交付清单](../../.project-control/0.11-development-plan.md#114-p7桌面与手机联动的联合交付)。

## 代码接线与联调入口

- 桌面`apps/desktop/runtime/companion-gateway.js`负责受限HTTPS网关、设备发现和二维码组装；主机`apps/api/app/companion/routes.py`提供配对入口。核对实际网关启用、证书、可达地址与正常Quit释放，不把匿名loopback服务直接开放到LAN。
- 手机`connection_sheet.dart`、`connection_invitation.dart`和`auth_session.dart`负责扫码解析与正式账号登录/刷新；`host_api.dart`按用途接受同账号配对或新成员邀请，再核验会话。配对不新增成员或占第二个名额，成员邀请仍遵守既有授权规则。
- `host_discovery.dart`查询桌面发布的`_yaohe._tcp`服务。发现仅提供候选地址，不能代替设备信任或成员授权；广播不得包含邀请、账号凭证或私人空间信息。
- `mobile_store.dart`安全保存连接并核验恢复；`host_api.dart`读取授权任务，`host_media_api.dart`读取媒体结果。离线记录保留更新时间，不作为当前完成事实。
- `transfer_controller.dart`与`mobile_transfer.dart`发送真实字节，按原请求查询、续传和确认主机接收；`voice_sampling_controller.dart`核对采样任务与文本版本。主机接收由已有素材/档案业务登记；收到素材不自动创建视频任务。

上述入口均位于当前源码，仍需在同一候选的真实手机和桌面上核验。源码接线、隔离测试或单端构建不能代替跨端联调。

## 账号资料的接入边界

用户资料由正式账号统一管理，手机不另建本机账号或把昵称当成员身份。当前手机已接入登录和刷新，展示会话姓名与设备角色；尚不提供手机注册、昵称修改或头像编辑。资料编辑仍需沿统一账号服务接入并独立验收，不自行猜测存储桶或用户表，不改变设备角色、空间授权或使用名额。

## 联调与验收

实施范围和写入归属遵循当前活动合同；协议变化先更新所属权威，再适配两端消费者，不以旧工作树或历史接线授予新写权。

手机独立验收相机扫码/图片识码、权限拒绝、无效内容、安全存储与离线状态。两端共同验收同账号配对、新成员邀请、真实进度、文件与声音接收、成片回看和两端重启恢复；邀请过期/撤销、成员停用、不可信证书、错设备或跨空间请求必须拒绝。地址变化重新核验，未知发送结果先对账；中断和重发不丢本地草稿、不重复登记。

Android与iOS分别记录同一候选的真实设备结果。隔离输入须显式区别于真实主机和账号，不用模拟成功、识码成功或收到文件代替完整联动通过。
