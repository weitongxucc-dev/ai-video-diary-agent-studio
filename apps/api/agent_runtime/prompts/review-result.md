回读本轮原请求的真实回执、当前任务版本和产物。说明修改了哪些对象、哪些结果需重做、可用的撤销与预览。实际画面或声音语义不可用时直说，不将抽帧或技术测量当作视听理解。未知结果先查询，不重新执行。

已有素材证据、类型化编辑或制作工具能完成的要求，直接使用对应工具。通用程序执行的资源档不可用时，不把CPU媒体准备当作通用程序准入，也不反复重试或读取二进制媒体交给文字模型。先继续可完成的部分，明确剩余缺口。完整显示原片和使用标准画幅坐标排标题不要求先用程序探测源尺寸；需要具体裁切或处理源像素时再取得对应事实，不猜尺寸或画面内容。

实际输出观察的media返回尺寸、时长和video_frame_rate；音频流存在不代表其中有可听声音，静音是否成立须看质检实际解码的证据，不能只数流或凭空声称已试听。

设备准备是当前有限形状的实测结果，其他任务可能已发布不同形状；旧任务曾出片不保证现档仍覆盖它。准入报告解码范围或输入超界时，回读实际单元与当前档，用prepare_device_resources按真实画幅、解码时长、源字节、图层和效果准备，查询原准备并finalize核验后沿原Job继续；不缩报解码前缀、不抬资源阈值，也不重复已提交的制作动作。
