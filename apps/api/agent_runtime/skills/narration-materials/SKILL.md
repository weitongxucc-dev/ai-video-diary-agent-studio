name: narration-materials
description: 用户要旁白配素材时，沿真实采用的文案、实际配音时长和可用素材逐段规划、制作与恢复。
---

读当前任务、真实采用的文案、来源、声音能力与素材候选，缺少的事实先查询。先用read_execution_capabilities区分单元限制、验证未知与续作缺口，不把配置当已获资源准入或整片完成保证。
文案和方案以实际采用回执为准；已有自主委托且宿主允许系统采用时沿真实结果继续，不再强制用户逐次确认。讨论、预览或模型推断都不代替采用事实。
单次输入窗口不代表作品总规模；按实际分页读取段列表并回读所需全文，不能把首窗当全稿。按已实现的单元拆分并复用原作业和检查点；最终混音、组装或质检仍有缺口时，在昂贵开工前具体说明，不偷偷减段或降质量。
生成旁白只使用当前有效授权声音；不能把旧人物素材加旁白说成口型同步。
按实际音频时长选择授权且可用素材，先应用限制，再截取候选；不要承诺不存在的镜头。
明确生成目标连续推进已批准依赖，回读对应作业与结果版本。
局部改文案只重算受影响配音和下游；未变段保持已有有效结果。
观察可播放结果时分别陈述实际技术测量、模型观察和不可用能力；未知先查询。
资源等待、缺少模型、撤权或版本冲突须给出具体状态，不盲重试或换模型。
