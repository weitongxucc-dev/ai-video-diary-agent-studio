---
name: narration-materials
description: 从本地资料和素材策划写稿，或采用既有定稿，安排旁白混剪、无对白演示与实际制作。
---

读当前任务、真实采用的文案、来源、声音能力与素材候选，缺少的事实先查询。先用read_execution_capabilities区分单元限制、验证未知与续作缺口，不把配置当已获资源准入或整片完成保证。
文案和方案以实际采用回执为准；已有自主委托且宿主允许系统采用时沿真实结果继续，不再强制用户逐次确认。讨论、预览或模型推断都不代替采用事实。
单次输入窗口不代表作品总规模；按实际分页读取段列表并回读所需全文，不能把首窗当全稿。按已实现的单元拆分并复用原作业和检查点；最终混音、组装或质检仍有缺口时，在昂贵开工前具体说明，不偷偷减段或降质量。
生成旁白只使用当前有效授权声音；不能把旧人物素材加旁白说成口型同步。
按实际音频时长选择授权且可用素材，先应用限制，再截取候选；不要承诺不存在的镜头。
明确生成目标连续推进已批准依赖，回读对应作业与结果版本。
局部改文案只重算受影响配音和下游；未变段保持已有有效结果。
观察可播放结果时分别陈述实际技术测量、模型观察和不可用能力；未知先查询。
资源等待、缺少模型、撤权或版本冲突须给出具体状态，不盲重试或换模型。

从目标开始时先 find_knowledge 读取资料依据，再 find_materials 查询本任务允许的资产，用 read_material_evidence 按源区间回查人工说明/纠正、声音与画面各自证据。检索分数只负责排序；背景、标签、用途和具体可见对象/动作分开，不以同类厂房证明指定生产线，不以声音提到某产品证明画面拍到了它。没有候选时区分授权范围、未分析与真实缺素材。

写稿前依据实际素材选择表达；写稿后逐段检查“说了什么、需要什么画面、哪个源区间支持、哪些只能作示意、还缺什么”。文案段可用稳定id和真实来源引用通过 start_script_window / patch_script_sections 保存；分页读完并核查后才 confirm_saved_script。已定稿或已锁定正文保持，不为了凑画面重写承诺；素材不足时明确缺口，优先寻找其他现有证据，必要的目标取舍才集中询问。

定稿到粗剪直接采用真实定稿，不强迫重写。用户提供已录音则沿既有录音采用；旁白仅在需要并有授权声音时生成。原声作品沿 source-speech；无对白设备/操作演示可从原片任务 preserve_audio=false 开始，按有证据的动作与顺序剪辑，使用可编辑图层说明，不为“没有声音”额外生成旁白。不要把临时切换静音误称已移除音轨。

首版先形成可播放结果；技术检查未结束就保留相应未检查状态，不等待虚构主观评分。后续改一句话、换一个镜头、调字幕分属不同依赖：改字幕不重配音；保留声音只换画面不移动声音；正文变化只失效相应段及真实下游。使用 local-edit 方法回查满意部分、修改范围和实际采用关系。不得把一个任务成功外推为所有风格或长作品已验证。
