---
name: local-edit
description: 用户要求修改现有视频的镜头、字幕、配音或效果时，固定引用版本、局部修改、回读并提供整组撤销。
---

先读取当前任务及冻结的选择；“这句、这个镜头”必须映射真实对象和版本。
多选与复合修改使用同一基础版本的原子操作。用户明确修改仍按API能力与当前授权保存；需要提案时以实际采用为准。
“向左一点”等已委托微调先读取选中对象、当前值、版本和实际画面。对象可唯一定位且可观察、可撤销时，自选小幅参数准备预览并回读效果，不要求用户提供精确像素；自选参数不是用户指定值。没有观察证据不声称效果达标；仍有多个实质对象、不可逆或需扩大范围时才澄清。
普通草稿编辑不自动启动媒体生成；“重配这一句、生成预览、继续制作”按其授权连续执行依赖。
每次写入回读原请求、实际版本、影响对象、失效的下游结果。未变段不重做。
运行中追加要求在安全点生效，已提交动作不能追改；后续要求保留原会话和顺序。
停止聊天、取消制作和撤销修改是不同动作；取消要有真实回执，撤销恢复整组版本。
回执未知先查原请求，不换绑当前版本或更换请求重复执行。

先明确本轮要保留的部分：当前采用正文、原声/旁白、已有标题/字幕、镜头顺序和人工改动。每轮从业务事实重读最新值；“再亮一点”“后一段更轻”等相对要求必须从现值计算，不把默认值覆盖未指定参数。不同轮精修不因存在旧预览而换回历史版本。

按疑点观察而非整片反复制作。read_material_evidence 读取原片的源时间文字证据；read_task_observations 读取已有输出观察与stale状态；observe_task_output 的 sample_times_seconds 只申请目标位置的有限画面采样。图层时间、字幕安全区、画面方向及切点各有具体定位；源证据不能证明合成后效果，技术音量不能证明听感。需要其他局部测量时先读原生工作目录和许可，再用现有工具，登记真实输出并沿原执行回读。

音频降噪、响度、局部音量及淡入淡出从 EditAudioTimeline 当前schema取值，修改后检查实际混音；duck_under_voice仅音乐轨，不能用加大降噪消除所有不明声音。字幕文字、时间、样式和翻译分别操作，保留人工断行及未指定轨；字幕纠错不等于改了语音或事实。未开放能力明确说明，不堆叠无效参数。

交付回查分别记录：动作是否保存、产物是否登记、是否采用为当前版本、可播放输出是否对应此版本、检查覆盖了什么。读实际媒体作业/制作回执而不是聊天“完成”；旧成片可保留作比较并标为历史。质量报告的确定性问题可定向修复，语义/听感未观察留给真实预览，不用合成信号或OCR替代。

一次任务完成时简报实际修改、保留/替换原因、未知和等待条件。成本只报告原回执能确认的模型/媒体运行与等待，不编节省比例、完成率或用户满意度。重新启动后从原任务、版本、原请求和实际Job继续，不能按聊天摘要另建作品或清预算。
