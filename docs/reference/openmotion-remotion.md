# OpenMotion 与 Remotion 借鉴评估

2026-11-20。目标是在同一作品页看见 Agent 对真实画面的修改，并将团队认可的动效复用于后续作品。本文记录产品方向、技术选项和验收案例。接入第三方运行时、桌面预览性能和最终画质均待实测。

## 品牌动效与团队复用

OpenMotion（nexu-io/openmotion）用 Motion.md 描述参考片的镜头顺序、时长和转场，并支持带入品牌素材、编辑场景和并排比较。曜核可从授权参考片提取标题入场、切镜、声音提示等时点，让用户单独调整某个动作。示例画面换成企业自己的镜头、字体和标志。[OpenMotion 官方说明](https://github.com/nexu-io/openmotion/blob/main/docs/README.zh-CN.md)

建议首批覆盖品牌片头、人物姓名条、口播关键词、数据对比、流程图解和章节转场。每项提供动态样例，列明可替换的文字、素材、颜色和时长。用户可通过已定的 A 版输入框用 `/` 选制作方法，用 `@` 引用团队风格或历史作品。在原片上调好后，明确保存为带版本的团队风格。同事制作英文版时沿用同一版本，换文案和旁白后能检查换行、遮挡和声音节奏。[输入工作台功能范围与验收](../design/assistant-composer-scope.md)

## Agent 修改与作品预览

Remotion 的播放器能根据合成参数和当前帧绘制画面，播放头可与时间线同步。曜核可沿用这套交互原理。Pi 解释指令，调用现有剪辑工具；工具按作品版本写入修改，回传对象、新版本及受影响的帧区间；作品页据此更新时间线和预览。人工拖动与 Agent 修改应使用同一份作品数据。[播放器](https://www.remotion.dev/docs/player/player) · [逐帧绘制](https://www.remotion.dev/docs/use-current-frame) · [时间线同步](https://www.remotion.dev/docs/building-a-timeline)

| 动作 | 对话栏 | 右侧作品页 |
|---|---|---|
| 查素材、读模板 | 原位显示正在执行的工具和结果 | 保留当前画面与播放头 |
| 修改已有标题、字幕或镜头 | 先显示正在处理，保存成功后说明改了哪一处 | 用真实素材和原声从改动前少许开始回放。用户正手动定位时，提供跳转入口 |
| 重做一句旁白或人物口型 | 标明正在生成的句子或片段，失败时可定位到该步 | 对应区间显示生成状态，可继续查看已有片段。新媒体就绪后可在原位试听或播放 |

现有代码已有按时间绘制的模板预览、位置/缩放/透明度关键帧，以及带作品版本的局部编辑预览入口。下一步先接通真实作品上的修改、预览、撤销和导出，再用同一段素材比较现有实现与 Remotion Player 的响应、画面一致性和桌面打包成本。[模板预览](../../apps/web/src/components/VisualTemplatePreview.tsx) · [关键帧](../../apps/web/src/components/TemplateKeyframes.tsx) · [作品编辑预览](../../apps/api/app/creation/editing/exact_preview_use_case.py)

## 实施与验收

1. 用已授权的科大管院视频做第一条闭环。在 30 fps 的验收作品中，把片头“数智分会”的入场设在第 60 帧，说“标题提前半秒”。右侧应显示它移到第 45 帧，用原声回放；撤销后回到第 60 帧。再次应用并导出，检查第 44 帧尚未入场、第 45 帧开始入场，同时核对旁白时点。Mac、Windows 分别记录从发送到工具发出正确指令、从保存成功到新画面出现的两段耗时。
2. 在真实采访、活动或产品片中验收首批动效。制作人可以逐项修改并试听，检查人物遮挡、字幕安全区、中英文换行和音画节奏。复杂动效可降低预览分辨率，入出帧和声音时点应与成片一致。
3. 用一个授权参考片验证团队复用。第一位成员拆解、修改并保存品牌风格；第二位成员在独立作品引用该版本，替换素材和英文文案，能从输入引用追溯到导出中实际采用的版本。

OpenMotion 主仓库采用 Apache-2.0，模板、字体、素材和第三方组件按各自来源核对再分发。若选用 Remotion，需分别核对部署方式适用的商业条款及独立 Timeline 组件授权。[OpenMotion 许可证](https://github.com/nexu-io/openmotion/blob/main/LICENSE) · [Remotion 条款](https://www.remotion.dev/docs/terms) · [Timeline 组件](https://www.remotion.dev/docs/timeline/)
