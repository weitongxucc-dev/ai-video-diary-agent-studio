# 2.0 Agent Content Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the first functional slice of 2.0 by making content templates, preference memory, and future performance insights actually influence Agent generation.

**Architecture:** Keep the existing FastAPI + EpisodeService + generator interfaces, but enrich generator calls with structured prompt context. The first implementation slice passes `ContentTemplate` from `Episode.content_template_id` into topic generation, full script generation, and section regeneration without changing UI flow.

**Tech Stack:** Python dataclasses, FastAPI, pytest, DeepSeek chat completions, Next.js contract checks.

---

## Scope

This plan is the practical starting point for completing 2.0. Full 2.0 includes macOS packaging, voice commands, analytics, and stronger memory, but the first shippable step is the highest ROI gap: make the existing content templates affect real Agent output.

## Files

- Modify: `apps/api/app/topics.py`
  - Extend `TopicGenerator.generate` to accept a `ContentTemplate`.
  - Add template context and scoring rubric to topic prompts.
- Modify: `apps/api/app/llm.py`
  - Extend `ScriptGenerator.generate` and `regenerate_section` to accept a `ContentTemplate`.
  - Add template context, section structure rules, and timing guidance.
- Modify: `apps/api/app/services.py`
  - Resolve `Episode.content_template_id` and pass the template through each generation call.
- Test: `apps/api/tests/test_2_0_prompt_context.py`
  - Verify template context reaches topic, script, and section-regeneration generators.
  - Verify DeepSeek prompt payloads include template-specific rules.
