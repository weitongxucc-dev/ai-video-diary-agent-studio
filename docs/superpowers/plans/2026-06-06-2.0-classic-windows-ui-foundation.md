# 2.0 Classic Windows UI Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Start the 2.0 upgrade with a visible, stable product slice: keep the classic old Windows pixel identity, add a reusable voice command console, and add a visual edit-plan workbench that explains what the Agent will cut, keep, review, and export before the Jianying draft import flow.

**Architecture:** Preserve the current Next.js app shell and existing business routes. Add one reusable component for voice commands, add one route for the edit-plan console, extend the sidebar/navigation shell, and add contract checks so the new 2.0 UI entry points cannot disappear silently.

**Tech Stack:** Next.js 15, React 19, TypeScript, CSS custom properties, existing pixel style contract scripts.

---

## Scope

This plan implements the first 2.0 UI foundation slice, not the full 2.0 backend:

- A new “剪辑计划” navigation entry and route.
- A bottom voice command console visible across the app.
- A static but product-faithful edit plan timeline showing cut/keep/review/effect segments.
- Classic old Windows styling only: zero radius, hard black borders, hard shadows, pixel panels, dot-matrix labels.
- Contract checks for route, component, and style tokens.

Out of scope for this slice:

- Real microphone capture.
- Real LLM command parsing.
- Real frame-accurate timeline edits.
- Actual Jianying effect JSON authoring.
