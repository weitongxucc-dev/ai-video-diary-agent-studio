## 编码线程如何接续

1. 保留当前分支、已有 diff 与用户数据，先核对活动 DESIGN.md 和相关领域章节。不要整包替换生产代码，也不要把示例数据写入真实业务。
2. 对照本页逐项标明已实现、需调整、尚未开始；复用已做好的搜索、输入、对象行和浮层底座。共享规则采纳后归项目现有 DESIGN.md，本包不成为第二份产品权威。
3. 将普通编辑落实为版本化草稿命令。撤销恢复对应草稿状态；成片、检查结果与输入版本匹配后才可恢复有效标记。不能照搬原型内存快照、盲目恢复旧成功状态。
4. 有实际费用时先取得真实报价与作用范围；费用无法取得时提供明确的下一步，不执行扣费。费用变化、实际授权与任务条件以现有契约为准。
5. 保持父卡挂载、输入、展开分组与滚动；子选项关闭只关子层。列表显示配置属于列表；对象分类属于具体对象。
6. 验收见 verification/v3验证说明.md。真实实施必须在同一代码候选验证实际数据、媒体比例、编辑撤销与输出版本；HTML通过不代表产品通过。
