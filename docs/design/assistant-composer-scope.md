# 曜核输入工作台 · 功能范围与验收

以 Mac 候选 b6de5a12 为现状基线。本表用于安排后续开发。每项的完成证据来自安装包中的用户操作与实际作品结果。

| 用户任务 | 可复用基础 | 需要交付 | 用户如何验收 |
|---|---|---|---|
| 附上本次资料，或把文件留给团队复用 | 本地素材导入、解析与检索 | ＋菜单、粘贴和拖入共用附件入口，明确显示“仅本轮使用”或“存入素材库”；可移除、重试 | 拖入简报和工厂片，只有选择入库的对象出现在团队素材库；失败文件可单独重试 |
| 引用现有资产和历史作品 | ＋与 @ 共用素材选择器，素材、资料、人物与声音有独立入口 | @ 统一搜索素材、切片、资料、历史作品，展示命中依据、可用状态、来源和固定版本；支持引用旧作品的选定部分 | 引用上月中文片的片头到新英文片，原作品保持原版本；停用素材提示换选 |
| 指定正在编辑的那一处 | 已有镜头、字幕、贴片、音频、旁白的“引用到对话”与作品版本绑定 | 工具栏选择模式，接入时间点、时间范围、文字稿选区和预览区域；能从引用返回原位置 | 选第二句字幕改一个词，右侧只更新该句；撤销回到原文。切换版本后过期引用提示重新选取 |
| 查命令、主动指定制作方法 | / 会话命令菜单，Pi 已声明原声口播、旁白配素材、局部改片等技能 | 技能按钮和 / 指向同一可用技能目录；区分立即执行的会话命令和附入草稿的制作技能，可检查依赖 | 点选或键入获得同一个技能及版本；发送前可移除，发送后可在对应步骤和结果中核对实际采用情况 |
| 复用设计风格 | 视频模板里的字幕样式、画面适配和可复用调色；项目已有风格与模板需求 | 风格选择器、真实预览、个人与企业风格版本；视觉风格与整片模板分别选择 | 对同一镜头切换两套品牌字幕，右侧预览与导出一致；语言、时长、声线保持原选择 |
| 选人物、声音和语言 | 人物与声音档案、版本、试听和作品制作入口 | 本轮可指定授权人物、中英声音与语言；就地试听，展示缺失依赖和授权状态 | 同一需求生成中英两版，两版可分别核对声线和字幕；替换英文声线能看见实际影响范围 |
| 选择工作模式和执行模型 | 当前文字服务、作品阶段、本机模型与设备能力检查 | 区分咨询、在原作品上剪辑及生成新媒体；只提供实际接通的执行选项；模型按文字、配音、口型、视频生成分用途呈现 | 询问素材只触发查询；明确编辑作用于原作品；设备或生成模型不可用时在开工前说明，并保留草稿 |
| 在长任务中补充、停止、恢复 | 当前轮次状态、追加要求、停止与既有回执 | 输入框清楚区分调整当前工作与排队下一项；失败发生处保留原因、已保存结果和可行操作；用量留在高级设置 | 中途追加只改英文版，中文继续沿用原要求；设备失败后恢复对应步骤，已完成的工作可回读 |
| 把成功经验交给下一位同事 | 现有素材、模板与制作技能，可固定来源版本 | 个人、团队及外部资源目录，覆盖技能、模板、风格和贴片；标明作者、许可、依赖、版本和停用状态。用户可把认可的作品做法提炼成团队技能 | 同事复用同一方法换一批新素材，得到独立作品；团队资产的修改、升级或停用可追溯 |

## 实施次序

1. **统一草稿和现有入口。** 附件、素材、作品选区、技能、风格、人物和声音拥有明确类型、目标与版本。点击按钮和输入快捷命令使用同一选择能力。先覆盖当前可执行的素材、选区、会话命令和内置技能，验证新对话隔离、历史恢复、键盘操作和窄窗。
2. **接通右侧作品。** 补齐历史项目、精确选区、风格预览、双语声线、模式与模型能力判断。每个选项都须能沿正式编辑或制作入口生效，在对应作品看到结果、范围和恢复方式。
3. **建成团队可复用的资源库。** 打通从认可作品提炼技能、保存品牌风格、安装兼容外部资源到他人复用的流程。沿用同一套输入入口，提供版本、授权、停用与替换。
4. **同一条企业视频贯穿三批。** 在原生 Mac 和 Windows 分别走完引用旧片、导入新素材、选技能和品牌风格、指定中英人物与声音、精修一处、恢复一次中断、导出两版、另一位成员复用。分别留存草稿、真实执行回执和导出结果。某项只有界面或只完成单平台时，按该范围记录。

布局沿用 A 版。空态目标高度约 80–84 个逻辑像素，多行内容随输入增长。高频入口常驻，低频选项归入有名称的菜单；窄窗仍可用键盘找到全部功能。公开工作说明和工具回执在对话原位显示，技术诊断在设置中按需读取。
