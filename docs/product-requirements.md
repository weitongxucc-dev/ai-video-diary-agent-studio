# AI 视频日记 Agent Studio 产品需求

状态：产品范围权威
职责：定义产品为谁解决什么问题、必须形成的用户闭环和长期边界；不记录当前开发进度。

## 1. 产品定位

AI 视频日记是一台面向内容操作人员的本地优先 AI 视频生产工作站。它把用户自己的内容、持续更新的外部信息、本地媒体素材、授权人物与声音、模型服务和平台账号组织为一条可检查、可复用、可定时运行的内容生产链。

产品不是只服务一种“知识口播”。口播、电商、外贸、教程、行业观察和产品演示是建立在同一套对象与流程上的场景模板；新增行业不应复制一套产品。

核心价值是让用户把注意力放在选题和关键审核上，而不是每次重复选择模型、人物、声音、素材、尺寸和发布步骤。

## 2. 目标用户

首要用户是负责选题、制作、审核和发布的一名操作人员或小团队。用户不需要理解向量、工作流编排或模型路由等内部术语，但需要：

- 管理自己的知识、品牌资料和历史内容；
- 配置外部信息源并持续获得新内容；
- 管理本地视频、音频、图片、镜头标签和使用记录；
- 复制经授权的人物形象和声音，制作中英文口型、字幕和发音；
- 从一次创作扩展到模板化、定时化和多平台运营；
- 在自动化过程中保留选题、事实、授权、成片和发布的决定权。

## 3. 产品主链

    自己的内容 + 外部信息源 + 本地素材 + 人物与声音
    → 自动搭建可运行方案
    → 选题
    → 文案、声音、人物口型和画面制作
    → 可视化剪辑、字幕、封面和平台尺寸
    → 审核
    → 发布或生成平台草稿
    → 定时回收数据、告警和复盘
    → 成功任务保存为视频模板
    → 视频模板创建自动任务并持续运行

首页允许用户用自然语言描述目标。系统根据当前可用内容和连接能力生成可编辑的执行方案，明确已就绪项、缺失项、人工确认点和首次试跑结果。系统不能在缺少授权、来源或必要连接时伪造可运行。

## 4. 产品对象与模块

产品必须围绕以下用户可理解的对象组织。详细关系与状态见 [domain-model.md](domain-model.md)。

| 模块 | 用户结果 |
| --- | --- |
| 首页 | 用一句话搭建方案，处理今天需要确认的事项，并查看运行通知 |
| 素材库 | 导入视频、音频和图片；识别镜头、标签、版权、用途、使用记录和素材缺口 |
| 内容资料 | 分开管理自己的知识库和从外部持续获取的信息源 |
| 人物与声音 | 管理人物形象、声音复制、授权、版本、发音词典和中英文口型能力 |
| 创作任务 | 并行运行一次完整制作，保存阶段状态、人工决定、失败原因和恢复点 |
| 视频模板 | 保存已经跑通的完整做法，复用来源、风格、人物、素材、字幕、封面、审核和发布要求 |
| 自动任务 | 把模板与时间或触发器、来源范围、审核点、通知和重试规则组合后持续运行 |
| 发布与数据 | 生成平台草稿、审核后发布或导出，并定时回收指标、异常和改进建议 |
| 模型与 API | 连接主流文字、图片、语音和本地模型，按任务选择质量、成本或隐私策略 |

## 5. 关键能力边界

### 5.1 知识库、信息源与素材库

- **知识库**保存用户已经拥有并有权使用的文字、文档、链接、字幕和结构化资料。
- **信息源**连接外部平台、频道、账号、关键词、订阅或网页，按授权和平台能力定时获取视频、图文、字幕、描述和链接。
- **素材库**保存用于成片的本地视频、音频、图片及其镜头片段，不与知识库或信息源混为一个列表。
- 三者都可通过转换进入制作：文字可以生成选题和文案，外部视频可以在许可允许时进入候选素材，本地媒体可以按语义、质量、比例、版权和近期使用情况自动匹配。
- 外部采集必须遵守平台条款、账号权限和内容授权；不承诺无限制抓取或绕过平台限制。

### 5.2 人物、声音、字幕和发音

- 人物形象和声音复制必须绑定明确授权、使用范围、有效状态和版本。
- 同一人物可有多个形象与声音版本，支持中文、英文和中英混合文案的发音词典与口型检查。
- 生成失败、低置信或授权失效时只阻断依赖该能力的步骤，并告诉用户影响和修复动作。

### 5.3 制作与可视化剪辑

- 制作任务必须串联选题、事实来源、文案、配音、人物口型、选片、剪辑、字幕、封面、尺寸、审核、发布和监控。
- 编辑界面提供播放器、故事板或受控时间线，支持片段替换、裁剪、排序、锁定、声音与字幕调整、人物口型检查、比例修正和平台版本预览。
- 产品不是通用专业 NLE，不承诺无限多轨、关键帧动画、复杂调色、插件宿主或专业音频混音台。
- 系统保留选片原因、标签、使用记录、人工修改、生成版本、失败原因和恢复点。

### 5.4 模板与自动任务

- 一次创作任务是一次执行；视频模板是可重复使用的方法；自动任务是模板加触发条件和运行规则。三者不得混用名称。
- 成功任务可以保存为模板。模板变更要有版本，已运行的任务保留当时使用的版本。
- 自动任务可以定时收集、生成候选选题、制作初稿、等待审核、发布和监控；用户可为选题、事实、成片和发布分别设置人工确认。
- 单次运行失败不能污染其他任务；断电、应用重启或移动硬盘移除后必须从可确认状态恢复。

### 5.5 模型与检索

- 支持主流云端和本地文字模型，通过任务路由选择高质量、平衡、低成本或本地隐私策略；不能把某一供应商写死为产品概念。
- 文字检索模型用于知识库、信息源、字幕和文案；图文/视频检索模型用于文案与视频帧、产品图和补充画面的匹配。两类索引必须分开定义和版本化。
- 图片模型用于封面和必要的视觉资产；语音、人物和口型服务使用各自明确的能力接口。
- 某个可选模型未配置时，只阻断依赖它的功能并给出替代或配置入口；安全、授权、越权和历史覆盖不得降级。

### 5.6 发布与监控

- 平台连接按实际能力支持“导出文件、生成草稿、确认后发布”中的一种或多种，界面必须说明当前方式。
- 自动发布必须经过用户明确授权，并允许模板或自动任务设置发布前审核门。
- 发布后可在 1 小时、24 小时、7 天或自定义时间回收数据，形成通知、异常和模板改进建议。
- 平台登录失效或接口受限时不能声称发布成功；其他平台和制作任务应继续运行。

## 6. 本地优先与数据边界

本地视频、音频、图片、模型权重、缓存、草稿和 AI 密钥默认留在用户设备。云端模型或平台连接会发送哪些内容，必须在连接或执行前说明。

大模型运行环境和缓存写入用户确认的目录；移动硬盘未挂载或空间不足时明确阻断，不静默改用内置盘。身份与 workspace 的安全不变量由 [auth-workspace-boundary.md](auth-workspace-boundary.md) 定义。

## 7. 非目标

- 多人实时协同编辑、计费系统或公开注册。
- 绕过平台访问控制、批量盗取内容或未经授权使用人物、声音和媒体。
- 完整替代 Premiere、Final Cut Pro 或 DaVinci Resolve 的专业后期能力。
- 在未确认影响时自动删除源素材、覆盖历史输出、改变模板版本或跨 workspace 共享私人内容。

## 8. 端到端验收

产品能力只有在真实界面中形成以下闭环才算完成，孤立 API、隐藏状态、静态 Demo 或构建成功不能替代：

1. 用户在首页描述目标，系统利用当前资料和能力生成可修改、可预检、可试跑的方案。
2. 用户能区分并管理知识库、外部信息源和本地素材，镜头标签、审核、使用记录和缺口可见。
3. 一条创作任务能经过选题、制作、人物声音、口型、可视化剪辑、字幕封面、审核、发布和监控，并可从失败点恢复。
4. 已跑通任务能保存为视频模板；模板能创建自动任务；自动任务按计划并行运行，只在配置的审核点打断用户。
5. 口播、电商、外贸和教程至少各有一条基于同一核心流程的可运行模板，不复制成四套产品。
6. 文字、图片、语音、人物和检索能力的连接状态、影响范围和修复动作对普通用户可理解。
7. 1024×768、1180×800 和 1440×900 下，左侧导航与并行任务、中间主工作区、右侧参数或运行看板均可完成核心操作。
8. 交付给他人使用的安装包还必须满足实际 Release 文档、workflow、身份模式和真实 Electron 验收。
